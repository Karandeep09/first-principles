# first-principles

Building things from scratch to understand how they actually work.

## Topics

- [transformer/](transformer/) — self-attention, masked self-attention, encoder–decoder attention
- [http-response/](http-response/) — HTTP status codes and responses over a raw TCP socket
- [postgres-query-optimization/](postgres-query-optimization/) — a shadow planner that predicts PostgreSQL's row estimates, costs and join orders from its statistics
- [mysql-query-optimization/](mysql-query-optimization/) — a shadow optimizer that predicts MySQL/InnoDB's access paths, row estimates and join orders from its statistics
